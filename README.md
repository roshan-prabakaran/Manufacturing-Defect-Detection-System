# Manufacturing Defect Detection System

An AI-powered system for detecting surface defects in manufacturing products (casting pump impellers) using CNN.

## 🚀 How to Host on Streamlit Community Cloud

1.  **Upload to GitHub**:
    - Create a new repository.
    - Upload all files including `app.py`, `model.py`, `best_defect_model.keras`, and `requirements.txt`.
2.  **Deploy**:
    - Go to [Streamlit Cloud](https://share.streamlit.io/).
    - Connect your GitHub account.
    - Select this repository and the main file `app.py`.
    - Click **Deploy**.

## 💻 Local Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`

## 📊 Documentation
Formal reports and project manifest are available in the `Final_Documentation` and `Final_Documentation_PDF` folders.
